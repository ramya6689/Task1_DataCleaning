# Task1_DataCleaning
Data Cleaning using Excel (Sales Data)

#Objective
Cleaned and prepared raw Sales Data from Kaggle by removing duplicates, handling null values, and standardizing formats.

# Tools Used
- Excel (Data Filters, Remove Duplicates, Conditional Formatting)
- Functions: TRIM, UPPER, TEXT, IF, etc.

# Steps Performed
1. Removed 12 duplicate rows using "Remove Duplicates".
2. Handled missing values by replacing blanks with 0 or appropriate text.
3. Standardized date column to dd-mm-yyyy format.
4. Added Month and Year columns using TEXT() and YEAR() functions.
5. Cleaned column headers (renamed to lowercase, no spaces).
6. Checked data consistency and corrected spelling in Country names.

## Outcome
Created a clean dataset ready for data analysis and visualization.

- Sales_Data_Original.csv
- Sales_Data_Cleaned.xlsx
- README.md (summary)
